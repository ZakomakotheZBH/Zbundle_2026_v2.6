ZTK Business Edition v3.0

Enterprise · Ultimate

ZTK Shell

v3.0.0 · Codename Phoenix

ISO C11 compliant, multi‑threaded TUI operating layer with DeepSeek AI, text games, disk management, and a full plugin system.

  • 🤖 ZewAI Bot (DeepSeek API)
  • 🎮 Snake, Tetris, Pong, Space Invaders
  • 🌐 Terminal browser (text‑mode)
  • 💾 Mount / format / partition
  • ⚙️ Self‑modifying code
  • 📦 Plugin & container support
Compilation

Linux / macOS

# install ncurses (Debian/Ubuntu) sudo apt install libncurses5-dev libncursesw5-dev # compile gcc -std=c11 -Wall -Wextra -o ztk ztk_bootloader.c -lpthread -lncurses # run with AI token ./ztk --ai-token YOUR_DEEPSEEK_TOKEN

Windows (MinGW)

gcc -std=c11 -Wall -Wextra -o ztk.exe ztk_bootloader.c -lpthread ./ztk.exe

Requires libcurl, sqlite3, crypt for full features.

AI Token: Set your DeepSeek token via --ai-token or inside the shell with ai init <token>.

Plugins: Place .so files in ~/.ztk/plugins/ and load with plugins load <name>.

ZewpolOS micro

x86 · 32‑bit

ZewpolOS micro

v1.0 · RAM‑based

Minimalist x86 protected‑mode operating system with a built‑in text editor, calculator, Pong, file manager, and a 64KB RAM filesystem.

  • 📁 RAM filesystem (16 files, 64KB)
  • 📝 Hex / text editor with navigation
  • 🧮 Calculator, Pong, Settings
  • ⌨️ Shell with commands: help, list, edit, calc, pong, fm
  • 💾 Persistent storage via RAM
Build

Compile for x86

# compile kernel gcc -m32 -ffreestanding -nostdlib -fno-stack-protector -c ZewpolOS-micro.c -o zewpol.o ld -m elf_i386 -Ttext 0x100000 -nostdlib -o zewpol.elf zewpol.o objcopy -O binary zewpol.elf zewpol.bin # combine with bootloader (see source)

Can be booted from floppy or used with QEMU: qemu-system-i386 -kernel zewpol.bin

FAQ & Tips

How do I use the AI in ZTK?
Set your DeepSeek token with --ai-token TOKEN or inside the shell ai init TOKEN. Then use ai ask "question" or enter chat mode.

Can I play games in ZewpolOS 7 web?
Yes! Type games list to see all games, then games play <name> to launch.

What are ZOS Tickets?
ZOS Tickets are the in‑app currency for ZOS StreamOS. Earn them by watching content or using promo codes, then spend them in the store.

Can I modify these OSes?
Absolutely. All source code is provided. ZTK is self‑modifying, ZewpolOS 7 web is pure HTML/CSS/JS, and ZewpolOS micro is C.

How do I install plugins in ZTK?
Place .so files in ~/.ztk/plugins/ and use plugins load <filename>.
