# System requirements
system requirements for each OS

## System requirements for ZTK 3
1. A computer that is eligable to run windows 7 and up
2. 195KB of storage or more to install games and apps
3. an SSD or really new hard drive
4. a proccesor that is newer then 2011
5. DDR3 ram or later

## System requirements for ZewpolOS 7 web
1. chrome newer then 2013
2. 5KB of localstorage
3. 1 tab open

## System requirements for ZOS TV streamOS 
1. chrome newer then 2017
2. 2KB of localstorage
3. 1 tab open

## System requirements for ZewpolOS micro
1. 3 MB of storage or more
2. any computer newer then 1994
3. a computer that supports ISOs made in C not only C++
